# Sample Data

Place captured session directories here for analysis.

Each session directory should contain:
```
session_YYYYMMDD_HHmmss_XXXXX/
  accel_YYYYMMDD_HHmmss_XXXXX.csv
  gyro_YYYYMMDD_HHmmss_XXXXX.csv
  mag_YYYYMMDD_HHmmss_XXXXX.csv
  gps_YYYYMMDD_HHmmss_XXXXX.csv
  meta_YYYYMMDD_HHmmss_XXXXX.json
```

Transfer sessions from your phone via USB from:
`Android/data/fr.nidsdepoule.capture/files/capture_sessions/`
